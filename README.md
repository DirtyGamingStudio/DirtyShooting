# Dirty Shooting

Dirty Shooting is a first-person survival shooter set in a dark urban park. Players must stay alive while facing increasingly dangerous waves of enemies.

Built with Unreal Engine 5, the project features FPS combat, health and armor systems, progressive enemy difficulty, a cinematic main menu, pause and death screens, and a complete settings menu.

## Features

- First-person shooter gameplay
- Enemy and wave-based survival system
- Health, armor, and HUD
- Pause menu with return-to-main-menu option
- Video, gameplay, and controls settings
- Master volume, mouse sensitivity, FOV, and invert Y-axis options
- Full HD resolution limit and Low graphics as the default for new players
- Rebindable keyboard controls
- Cinematic video background in the main menu
- Responsive UI for different screen resolutions

## Technologies

- Unreal Engine 5.4
- Blueprints
- C++
- Enhanced Input
- Unreal Media Framework
